# Raw Data Directory

Place your raw social media campaign data files here.

## Supported Formats:
- CSV files (.csv)
- Excel files (.xlsx, .xls)

## Expected Columns:
Your data file should contain columns such as:
- Date/Time information
- Campaign/Ad identifiers
- Impressions
- Clicks
- Spend/Cost
- Reach
- Engagements
- Conversions (optional)
- Revenue (optional)
- Demographics (age, gender, device, region, etc.)

## Example Files:
- `campaign_data.csv`
- `facebook_ads_data.csv`
- `instagram_ads_data.xlsx`
